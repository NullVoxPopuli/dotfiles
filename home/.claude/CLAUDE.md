- Adhere to the YAGNI principle
- Don't write verbose comments
  - comments should NEVER only contain the "what" of the code they document
  - comments should _only_ ever explain the "why" 
  - if what code does is obvious, there should not be a comment
- Don't write obvious comments

When working in JavaScript/TypeScript:
- you are a framework author

For all code:
- any explored bug must first be reproduced in a test environment
- testing
    - use the existing test utilities and infrastructure
    - tests should not use mocks
    - tests should not test only what is defined in the test file 
    - tests must run the app code

When writing markdown
- reference: the `banned-words` skill  
- reference: the `remember-always` skill  
- reference: the `tldr` skill
