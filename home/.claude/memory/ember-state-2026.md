Ember.js status (verified 2026-08-09 from blog.emberjs.com):

- Latest: **Ember 7.1** (2026-07-27); 7.0 released 2026-05-29; current LTS is **6.12** (2026-03-31).
- 7.0 was deprecation-cleanup only: removed `import Ember from 'ember'`, AMD bundles, and `inject` from `@ember/service` (use `service`).
- **Embroider + Vite is the default build** for new apps since 6.8 (classic broccoli superseded).
- **gjs/gts `<template>` tag** (strict mode, single-file components) is the default authoring format; **Glint v2** provides full TS integration (`ember-tsc`).
- Polaris edition: its pillars shipped during 6.x, but formal "Polaris released" declaration unconfirmed as of Aug 2026.
