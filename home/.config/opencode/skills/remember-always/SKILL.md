## When writing prose

- avoid LLM spew
- avoid all the banned words and phrases and formatting
- avoid "marketing structure": short sentences. pause for effect. 
- do not repeat yourself
- do not explain things that were explained elsewhere in the document
- do not provide implementation details about a problem when not asked -- high level is fine. humans can figure out implementation on their own.
- adhere to the adhd-friendly-writing skill
- adhere to the tldr writing skill

- always: be precise with word choice
- always: be concise in sentence structure and length

## When writing code

in comments, adhere to the "writing prose" guide above.

- avoid: multiple line comments
- avoid: comments that explain "what" instead of "why"
- avoid: explaining what should be details on the PR
- avoid: ephemeral context in comments

- never: use effects (useEffect, didInsert, didUpdate, onMount, etc)

comments should be long-lasting context that humans would not be able to discern from reading the code.
