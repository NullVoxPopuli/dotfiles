# Global OpenCode Instructions

These instructions apply to every OpenCode session for this user.

## Persistent Memory

- Read `memory.md` when durable personal context is relevant.
- Update `memory.md` when the user explicitly asks to remember something, or when they establish a stable preference, workflow convention, environment fact, or recurring project-independent decision that will materially improve future sessions.
- Do not record secrets, credentials, private personal data, transient task details, or speculative conclusions.
- Keep entries concise, factual, and deduplicated. Prefer updating an existing entry over adding a duplicate.
- Do not update memory merely because a task was completed. Record only information that is useful beyond the current task.
- When updating memory, mention the change briefly in the final response.

## Working Style

- Inspect the existing configuration and repository state before editing.
- Preserve unrelated user changes.
- Prefer the smallest correct change and verify configuration edits before finishing.
